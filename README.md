# أرشيف عبد الحليم حافظ — دليل الاستخدام والتشغيل

تطبيق ويب عربي (RTL) لأرشفة أعمال عبد الحليم حافظ: الأغاني وتسجيلاتها المتعددة، الحفلات، الجلسات، المقابلات، الأفلام، الصور، الملحنين والشعراء، الخط الزمني، والتسجيلات النادرة — مع مشغل صوتي ثابت ولوحة تحكم كاملة.

> المشروع لا يحتوي افتراضيًا على أي ملف صوتي أو صورة لعبد الحليم. كل الوسائط تُضاف منك فقط، من ملفات تملك حق استخدامها.
> البيانات التاريخية المبدئية قليلة ومأخوذة من ويكيبيديا (العربية والإنجليزية) ومرفقة بالمصدر ودرجة التأكد. أي معلومة غير موثقة تظهر كـ«بيانات تحتاج إلى إدخال».

---

## الفكرة الأساسية: الكود منفصل عن البيانات

```
halim-archive/            ← كود التطبيق (يمكن حذفه وإعادة بنائه في أي وقت)
archive-data/             ← بياناتك أنت (لا تحذفه أبدًا)
  ├── archive.db          ← قاعدة البيانات (SQLite)
  ├── media/audio/        ← ملفات MP3
  ├── media/images/       ← الصور
  └── backups/            ← النسخ الاحتياطية
```

مكان مجلد البيانات يُحدَّد بمتغير البيئة `ARCHIVE_DATA_DIR`. إذا لم تحدده يُستخدم `./archive-data` بجانب الكود (مناسب للتجربة فقط). في النشر الحقيقي ضعه على قرص/Volume دائم خارج مجلد الكود، مثل `/data`.

عند تشغيل نسخة جديدة من الكود، تقوم قاعدة البيانات بإضافة أي أعمدة أو جداول جديدة تلقائيًا **دون حذف أي شيء**، ولا تُعاد البيانات المبدئية إذا كانت القاعدة موجودة مسبقًا.

---

## 1. أين أضع ملفات MP3؟

الطريقة الأسهل: **لوحة التحكم ← رفع الملفات ← ملفات MP3**، واسحب الملفات (مئات الملفات دفعة واحدة ممكن). يمكنك كتابة مجلد فرعي مثل `1976` أو `concerts/1976` للتنظيم.

أو يدويًا: انسخ الملفات مباشرة إلى:
```
archive-data/media/audio/
archive-data/media/audio/1976/qariat-alfingan-live.mp3   ← مثال
```
ثم استخدم المسار النسبي `audio/1976/qariat-alfingan-live.mp3` في حقل «ملف MP3» للتسجيل.

- الملفات لا تُحمَّل إلا عند الضغط على تشغيل.
- يمكن أيضًا وضع رابط https مباشر لملف صوتي مستضاف في مكان آخر (مثل خدمة تخزين سحابي).
- يفضل أسماء ملفات إنجليزية بدون مسافات.

## 2. أين أضع الصور؟

نفس الطريقة: **لوحة التحكم ← رفع الملفات ← الصور**، أو يدويًا في:
```
archive-data/media/images/
```
المسار المستخدم في الحقول يكون مثل `images/concerts/1976-01.jpg`.
الصورة الرئيسية في الصفحة الأولى تُحدد من **لوحة التحكم ← الإعدادات والنسخ الاحتياطي**.

## 3. كيف أضيف أغنية؟

1. افتح `#/admin` وسجّل الدخول.
2. تبويب **الأغاني** ← **إضافة أغنية**.
3. اكتب الاسم (الحقل الإجباري الوحيد) ونوع الأغنية.
4. في الملحن / الشاعر / الموزع / الفيلم: ابحث واختر، أو اكتب اسمًا جديدًا واضغط «إضافة … جديد» وسيُنشأ تلقائيًا.
5. التاريخ: إذا لم تكن متأكدًا لا تكتب سنة؛ اختر «غير مؤكد» أو «غير معروف». للتقدير اكتب «من سنة» و«إلى سنة» (مثال 1965 – 1967) وسيظهر: «التاريخ غير مؤكد — يرجح أنه بين 1965 و1967 (تقدير)».
6. احفظ، ثم أضف المصادر ودرجة التأكد من خانة «المصادر ودرجة التأكد» التي تظهر بعد الحفظ (يمكن أكثر من مصدر لكل معلومة).
7. لإضافة الصوت: تبويب **التسجيلات و MP3** ← إضافة تسجيل ← اختر الأغنية، نوع التسجيل (استوديو، حي، إذاعي، سينمائي…)، وارفع ملف MP3. **الأغنية الواحدة يمكن أن يكون لها عدد غير محدود من التسجيلات**، وتظهر في صفحتها تحت «نسخ أخرى من الأغنية».

طريقة أسرع للصوت: ارفع الملفات من «رفع الملفات»، ثم اضغط «إنشاء تسجيل» بجانب كل ملف غير مرتبط.

## 4. كيف أضيف حفلة؟

تبويب **الحفلات** ← إضافة حفلة: الاسم، المناسبة، التاريخ، المسرح، المدينة، الدولة، الصورة، رابط فيديو، الوصف والتاريخ.
قائمة أغاني الحفلة = التسجيلات المرتبطة بها: عند إضافة تسجيل اختر الحفلة في حقل «الحفلة»، ورقّمه في «الترتيب في الحفلة». صور الحفلة: اربط الصورة بالحفلة من تبويب الصور.

## 5. كيف أضيف مقابلة؟

تبويب **المقابلات** ← إضافة مقابلة: العنوان، البرنامج، المذيع، الجهة، التاريخ، المدة، ملف الصوت أو رابط الفيديو، والملخص/النص.

## 6. كيف أضيف جلسة؟

تبويب **الجلسات** ← إضافة جلسة: العنوان، المكان، المدينة، التاريخ، الحضور، الوصف. ثم أضف تسجيلاتها من تبويب التسجيلات مع اختيار الجلسة. لتظهر في «التسجيلات النادرة» فعّل «تسجيل نادر» واختر التصنيف.

## 7. كيف أضيف صورة؟

تبويب **الصور** ← إضافة صورة: الملف، العنوان، التصنيف (شخصية، الطفولة، الحفلات، الاستوديو، الأفلام، مع الفنانين، مع الملحنين والشعراء، نادرة، الصحافة، السفر)، أبيض وأسود / ملونة، التاريخ، المكان، الأشخاص، المصدر، والربط بحفلة/فيلم/شخص/أغنية.
لإضافة صور كثيرة: ارفعها من «رفع الملفات» ثم «إضافة كل غير المرتبطة للمعرض»، وأكمل بياناتها لاحقًا.

## 8. كيف أضيف بيانات كثيرة دفعة واحدة؟

**لوحة التحكم ← استيراد وتصدير**:
1. اختر النوع (أغاني، تسجيلات، صور…) ونزّل **قالب CSV**.
2. املأه في Excel أو Google Sheets واحفظه **CSV UTF-8**.
3. اختر الملف واضغط استيراد. تظهر النتيجة (عدد المضاف/المحدث والأخطاء).

قواعد مهمة:
- أعمدة الربط (`composer`, `lyricist`, `song`, `concert`, `movie`…) تقبل **الاسم نصًا**؛ يُربط تلقائيًا أو يُنشأ.
- أعمدة القوائم تقبل القيمة الإنجليزية أو التسمية العربية، مثل `romantic` أو `أغنية عاطفية`، و`live` أو `تسجيل حي`.
- درجة التأكد: `confirmed` مؤكد، `likely` مرجح، `uncertain` غير مؤكد، `unknown` غير معروف.
- وجود رقم في عمود `id` = تحديث السجل الموجود.
- ترتيب الاستيراد المقترح: الأشخاص ← الأفلام ← الحفلات/الجلسات ← الأغاني ← التسجيلات ← الصور.
- ملفات أمثلة في مجلد `samples/`.
- يقبل أيضًا JSON (مصفوفة كائنات)، أو ملف التصدير الكامل لاستعادة الأرشيف كله.

## 9. كيف أحفظ قاعدة البيانات؟

ثلاث طرق، استخدم أكثر من واحدة:
- **لوحة التحكم ← الإعدادات والنسخ الاحتياطي ← إنشاء نسخة احتياطية الآن**: تُحفظ في `archive-data/backups/` ويمكن تنزيلها.
- **تصدير كامل JSON** من تبويب الاستيراد والتصدير (ملف واحد يحتوي كل البيانات، يمكن استيراده على أي خادم).
- انسخ مجلد `archive-data/` كاملًا (القاعدة + الوسائط) إلى قرص خارجي أو تخزين سحابي بشكل دوري. الأهم هو هذا المجلد.

للاستعادة: أوقف التطبيق، ضع `archive.db` (أو المجلد كاملًا) مكانه، ثم شغّل التطبيق.

## 10. كيف أعيد Build؟

```bash
npm install
npm run build          # ينتج dist/ (الواجهة + الخادم)
npm start              # يشغل على المنفذ 5000
```
للتطوير: `npm run dev`. البناء لا يلمس مجلد البيانات إطلاقًا.

## 11. كيف أعيد Deploy؟

**بـ Docker (موصى به على أي VPS):**
```bash
cp .env.example .env         # عدّل ADMIN_PASSWORD و ADMIN_SECRET
docker compose up -d --build # أول مرة وبعد كل تحديث للكود
```
ملف `docker-compose.yml` يربط `./archive-data` على الخادم بـ `/data` داخل الحاوية، فإعادة البناء تستبدل الكود فقط.

**بدون Docker (خادم Node):**
```bash
git pull   # أو انسخ الكود الجديد
npm install && npm run build
ARCHIVE_DATA_DIR=/srv/halim-data ADMIN_PASSWORD='...' npm start
```
استخدم `pm2` أو `systemd` لإبقائه يعمل.

**منصات الاستضافة (Railway / Render / Fly.io):** أنشئ **Persistent Volume** واربطه بمسار مثل `/data`، واضبط `ARCHIVE_DATA_DIR=/data` و`ADMIN_PASSWORD`. أمر البناء `npm run build` وأمر التشغيل `npm start`.

> ملاحظة: الاستضافات «الثابتة» فقط (مثل Vercel للملفات الثابتة) لا تحفظ قاعدة بيانات أو ملفات مرفوعة؛ هذا التطبيق يحتاج خادم Node مع قرص دائم.

## 12. كيف أتأكد أن الملفات والبيانات لن تضيع بعد إعادة النشر؟

قبل كل إعادة نشر:
1. أنشئ نسخة احتياطية من لوحة التحكم ونزّل **تصدير كامل JSON**.
2. تأكد أن `ARCHIVE_DATA_DIR` يشير إلى Volume دائم وليس داخل مجلد الكود.

بعد إعادة النشر:
1. افتح **لوحة التحكم ← الإعدادات**: تحقق أن «مجلد البيانات» هو نفس المسار، وأن عدد الملفات الصوتية والصور وحجم القاعدة كما كان.
2. افتح `/api/health` — يعرض مسار مجلد البيانات الفعلي.
3. شغّل أغنية وافتح صورة للتأكد.

إذا ظهر الأرشيف فارغًا فهذا يعني أن التطبيق يقرأ من مجلد جديد: أوقفه، صحح `ARCHIVE_DATA_DIR`، وأعد التشغيل. بياناتك لم تُحذف، فهي ما تزال في المجلد القديم.

## التوسعة
- اللغة: النصوص في `client/src/lib/i18n.ts` وتسميات الحقول ثنائية اللغة في `shared/registry.ts`، لذلك يمكن إضافة الإنجليزية لاحقًا دون إعادة بناء المشروع من الصفر.
- إضافة حقل جديد: أضفه في `shared/registry.ts` فقط؛ يظهر تلقائيًا في النموذج والاستيراد والتصدير، ويُضاف العمود إلى القاعدة تلقائيًا عند التشغيل.
- البحث مفهرس (SQLite FTS5) ويعمل مع آلاف السجلات، ويتجاهل اختلافات الهمزات والتاء المربوطة والتشكيل.
